# 深度学习课程选择分析

这一栏课程很多，最好按“通用基础 → 专项方向”选择，而不是从头到尾全部刷完。

## 通用深度学习

| 课程 | 特点 | 适合 |
| --- | --- | --- |
| Coursera Deep Learning | 入门友好、体系清晰 | 第一次系统学 DL |
| 李宏毅机器学习 | 中文、覆盖主题广 | 希望中文快速建立 ML/DL 全貌 |
| CMU 11-785 | 强度较高的深度学习课程 | 希望通过大量训练深化理解 |
| MIT 6.7960 | 更进阶的深度学习 | 已有 ML/DL 基础 |
| NYU DLSP21 | 系统讲解现代深度学习 | 想用另一套大学主干课深入 |

通用课选 1–2 门即可，不建议全部重复。

## 专项方向

- **计算机视觉**：UMich EECS 498-007 / 598-005、Stanford CS231n。二者选一套主线即可。
- **自然语言处理**：Stanford CS224n。
- **图机器学习**：Stanford CS224w。
- **强化学习**：UCB CS285。

## 怎么选

第一次学可以 Coursera DL 或李宏毅入门，再用 NYU / CMU / MIT 中一门提高深度。之后根据方向选 CS231n、CS224n、CS224w 或 CS285。

## 建议路线

ML 基础 → 一门通用 DL → 一个专项方向 → 再进入生成模型 / LLM / ML Systems。
