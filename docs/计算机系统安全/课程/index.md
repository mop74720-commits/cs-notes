# 计算机系统安全课程选择分析

当前课程可以分成“安全入门”“系统安全进阶”和“实验训练”。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| UCB CS161 | 计算机安全综合入门 | 第一次系统学安全 |
| MIT 6.1600 | 安全基础课程 | 想建立较系统的安全基本概念 |
| MIT 6.858 | 高级计算机系统安全 | 已有系统与安全基础后深入 |
| ASU CSE365 | 网络与系统安全入门 | 希望从实践型安全课程进入 |
| ASU CSE466 | 更进阶的系统安全 | 已完成基础安全课程 |
| SEED Labs | 安全实验集合 | 想通过攻击/防御实验巩固概念 |

## 怎么选

第一门建议在 CS161、MIT 6.1600、CSE365 中选一套完整主线。**MIT 6.858 和 CSE466 更适合作为第二阶段**。

SEED Labs 的价值在于实践，可以与任何一门理论课程搭配，而不是替代完整课程。

## 建议路线

CSAPP + 网络/OS 基础 → CS161 / 6.1600 / CSE365 → SEED Labs → 6.858 或 CSE466。
