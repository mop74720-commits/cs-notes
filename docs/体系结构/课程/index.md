# 体系结构课程选择分析

当前课程从“亲手造一台计算机”到“现代处理器体系结构”形成了明显层次。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| Nand2Tetris | 从逻辑门到 CPU、汇编、编译器的自底向上构建 | 想建立直观完整的计算机结构认识 |
| UCB CS61C | C、机器表示、RISC-V、存储层次、并行等 | CS 学生进入体系结构的主干课 |
| ETH DDCA | 数字设计 + 计算机体系结构 | 想进一步理解硬件实现 |
| ETH Computer Architecture | 更进阶的处理器/体系结构内容 | 已有数字逻辑与基础体系结构背景 |

## 怎么选

Nand2Tetris 与 CS61C 都可以作为入口，但风格不同：前者强调“从零构建”的整体感，后者更接近标准大学体系结构课程。

ETH DDCA 适合想补数字电路和硬件设计的人；ETH Computer Architecture 放在最后更合适。

## 建议路线

- CS 主线：CS61C → ETH Computer Architecture。
- 喜欢动手：Nand2Tetris → CS61C。
- 硬件方向：Nand2Tetris / CS61C → DDCA → ETH Computer Architecture。
