# 编程入门课程选择分析

这一栏课程很多，但正确策略不是“全部学”，而是 **工具课 + 一门主语言课程 + 按方向补第二语言**。

## 工具与环境

| 课程 | 定位 | 选择建议 |
| --- | --- | --- |
| MIT Missing Semester | Shell、Git、编辑器、命令行工作流 | 几乎所有方向都值得先学 |
| Sysadmin DeCal | Linux / 系统管理实践 | 想增强服务器、Linux、运维基础时学习 |

## Python

- **UCB CS61A**：重点不只是 Python 语法，而是程序抽象、递归、高阶函数、解释器等计算思维。适合把它作为真正的 CS 编程入门。
- **CS50P**：更聚焦 Python 本身，入门平滑，适合只想快速掌握 Python。
- **MIT 6.100L**：用 Python 学计算与编程基础，适合偏学院式、系统化入门。

如果目标是长期学 CS，优先 CS61A；如果目标是尽快会 Python，CS50P 更直接。

## C / C++

- **Harvard CS50x**：广义 CS 入门，不只是 C；适合第一次建立完整计算机科学直觉。
- **Duke Introductory C Programming**：更集中地训练 C。
- **Stanford CS106L**：重点是现代 C++ 和标准库，适合已有编程基础的人。
- **Stanford CS106B/X**：更偏数据结构、抽象与程序设计。
- **AUT1400 Advanced Programming**：适合希望通过完整高级程序设计课程练 C++ 的学习者。

如果以后走系统方向，可在 Python 入门后补 C；如果走算法/工程，C++ 可选 CS106B/X + CS106L。

## Java

**MIT 6.092** 是当前栏目唯一 Java 入门课。目标是 Java 后端时可以直接用它建立语法和 OOP 基础，之后应尽快进入数据结构、JVM、数据库和工程项目，不必长期停留在语法阶段。

## Rust

- **Stanford CS110L**：从系统编程与安全性切入 Rust。
- **KAIST CS220**：更关注程序设计原则。
- **KAIST CS431**：并发编程，明显更进阶。

推荐顺序是先有 C/C++ 或系统基础，再 CS110L / CS220，最后按需要进入 CS431。

## 函数式语言

- **Cornell CS3110**：用 OCaml 学函数式编程、抽象和正确性，适合 CS 理论与 PL 方向。
- **Haskell MOOC**：更聚焦 Haskell 与纯函数式思想。

第一次接触函数式编程，二选一即可。

## 一条实用路线

Missing Semester → CS61A（或 CS50P）→ 根据方向选择 C/C++、Java、Rust 或函数式语言。不要为了“语言数量”重复上多门同层级入门课。
