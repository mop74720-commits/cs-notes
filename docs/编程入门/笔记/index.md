## 建议阅读顺序

1. **Java-知识库笔记**：先建立完整语言基础。
2. **Java-个人笔记**：用自己的学习记录补细节。
3. **并发学习笔记**：进入线程、锁、JUC。
4. **JVM 与 GC 面试**：补 JVM 运行时与 GC。
5. **面试-Java + 并发面试笔记**：最后做面试压缩复习。

如果只是临近面试，可以直接从三份 **“面试-”** 类笔记开始，再回到知识库查缺口。
