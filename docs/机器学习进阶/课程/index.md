# 机器学习进阶课程选择分析

这一栏按研究主题分得很清楚：概率图模型、生成模型、优化和学习理论。

| 课程 | 方向 | 更适合 |
| --- | --- | --- |
| 学习路线图 | 进阶方向导航 | 先确认自己要走哪条路线 |
| CMU 10-708 | Probabilistic Graphical Models | 概率建模、推断、图模型 |
| Columbia STAT 8201 | Deep Generative Models | 深度生成模型研究 |
| U Toronto STA 4273 | Minimizing Expectations | 随机优化 / 期望最小化相关方法 |
| Stanford STATS214 / CS229M | Machine Learning Theory | 泛化、理论 ML、学习理论 |

## 怎么选

这些课程之间不是层级关系，而是研究方向分支。先完成一门标准 ML 课程，再选择一个方向深入。

如果喜欢概率模型，选 10-708；喜欢生成模型，选 STAT 8201；对优化机制感兴趣选 STA 4273；想理解“为什么模型能泛化”等理论问题，选 STATS214 / CS229M。

## 建议路线

线代 + 概率 + 优化 + 一门标准 ML → 选择一个进阶方向深入。不要为了“课程数量”同时展开四条研究线。
