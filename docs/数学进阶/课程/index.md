# 数学进阶课程选择分析

这一组课程可以分成离散数学、概率、数值计算、优化和信息论/学习理论几个方向，不建议全部并行学习。

| 课程 | 定位 | 选择建议 |
| --- | --- | --- |
| UCB CS70 | 离散数学 + 概率 | 想把 CS 理论基础与概率一次串起来 |
| MIT 6.042J | 计算机科学离散数学 | 更关注证明、组合、图、离散结构 |
| UCB CS126 | 概率论 | 已掌握离散数学，希望继续加深概率 |
| MIT 18.330 | 数值分析 | 数值计算、科学计算、计算数学方向 |
| Stanford EE364A | 凸优化 | ML、优化、控制、信号处理方向的重要进阶课 |
| Information Theory, Pattern Recognition, and Neural Networks | 信息论与模式识别交叉 | 已有概率、线代基础，希望理解 ML 的信息论视角 |

## 怎么选

**CS70 与 6.042J 有明显重叠**，第一次学通常选一门即可。想更贴近 Berkeley CS 体系可以选 CS70；想系统训练离散数学和证明，可以选 6.042J。

概率基础不足时，再从 CS126 深挖。EE364A 不建议过早学，最好先具备线性代数、微积分和基本概率。MIT 18.330 则更偏数值计算，与算法、科学计算结合紧密。

## 建议路线

- CS 理论：CS70 或 6.042J → CS126。
- ML 数学：CS70/概率基础 → EE364A → 信息论/模式识别课程。
- 数值计算：微积分 + 线代 → MIT 18.330 → EE364A。
