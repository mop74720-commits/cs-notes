# 软件工程课程选择分析

三门课程关注点不同：代码构造、完整软件工程流程、以及软件工程研究方法。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| MIT 6.031 Software Construction | 正确性、抽象、测试、可维护代码 | 想提升代码质量和工程基本功 |
| UCB CS169 Software Engineering | 团队开发、工程流程、Web/项目实践 | 想体验较完整的软件工程协作 |
| CMU 17-803 Empirical Methods | 软件工程实证研究方法 | 准备做 SE 研究、论文、实验评估 |

## 怎么选

对于本科生和工程实习准备，MIT 6.031 与 CS169 的价值最直接，但二者侧重点不同。

先学 6.031 可以把“代码怎么写得可靠”打牢，再用 CS169 训练“多人项目怎么组织”。17-803 不属于普通开发必修，它更适合研究导向。

## 建议路线

6.031 → CS169 → 如果进入软件工程研究，再学 17-803。
