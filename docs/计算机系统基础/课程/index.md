# 计算机系统基础课程选择分析

这里两门课是很自然的前后衔接关系。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| CMU 15-213 / CSAPP | 从机器级表示到链接、内存、缓存、并发与网络的系统基础 | 几乎所有想深入系统的学生 |
| Stanford CS110 | 系统编程、进程、线程、并发和 OS 接口 | 已有 C/C++ 与系统基础，希望继续做系统编程 |

## 怎么选

如果只能选一门，第一次进入系统领域优先 **CMU 15-213 / CSAPP**，因为它覆盖面更基础，也能为 OS、网络、编译、性能分析建立共同语言。

CS110 更适合接在 CSAPP 后面，重点从“理解计算机系统”转向“使用系统接口构建程序”。

## 建议路线

CSAPP → Stanford CS110 → 操作系统 / 网络 / 分布式系统。
