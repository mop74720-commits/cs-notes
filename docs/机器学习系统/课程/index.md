# 机器学习系统课程选择分析

这一栏不是“同一种 ML Systems 课的六个版本”，而是覆盖了 ML 系统的不同层：通用系统、框架、编译、硬件、边缘部署和数据系统。

| 课程 | 方向 | 更适合 |
| --- | --- | --- |
| CMU 15-442/642 ML Systems | ML 系统全局视角 | 第一次进入 ML Systems |
| 智能计算系统 | AI 计算系统 / 软硬件协同 | 对 AI 加速器、计算架构感兴趣 |
| CMU 10-414/714 Deep Learning Systems | 深度学习框架与系统 | 想理解自动微分、Tensor、训练框架内部 |
| MIT 6.5940 | TinyML / 高效深度学习 | 边缘设备、压缩、推理效率 |
| Machine Learning Compilation | ML 编译 | 编译器、算子优化、模型部署 |
| UCSD CSE234 | Data Systems for ML | 数据基础设施、ML 数据系统 |

## 怎么选

第一次学建议先 **CMU 15-442/642** 建立全局图，再根据方向分支。

如果你关心“PyTorch 这类框架怎么工作”，选 10-414/714；关心编译优化选 MLC；关心边缘设备选 6.5940；关心数据管线和数据系统选 CSE234；关心硬件与加速器则选智能计算系统。

## 建议路线

ML 基础 + 系统基础 → 15-442/642 → 选择一个专项深挖，而不是六门全部横向重复。
