## 建议阅读顺序

1. **Docker笔记**：先具备容器化基础。
2. **SpringCloud笔记**：进入微服务体系。
3. **Frame**：扩展到中间件综合视角。
4. **分布式 / MQ / K8s&Docker 面试笔记**：最后按面试问题压缩知识。

这部分不建议一开始死记八股，最好先结合一个真实后端项目理解服务调用、缓存、消息、容器和故障场景。
