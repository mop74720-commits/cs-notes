# 并行与分布式系统课程选择分析

这里只有两门课，但它们不是替代关系。

| 课程 | 方向 | 核心问题 |
| --- | --- | --- |
| CMU 15-418 / Stanford CS149 | 并行计算 | 如何利用多核、SIMD、GPU 等提高单个计算任务吞吐 |
| MIT 6.5840 / 6.824 | 分布式系统 | 如何让多台机器在故障、网络延迟下协同工作 |

## 怎么选

如果目标是后端、云服务、分布式存储，一般优先 **MIT 6.5840**。如果目标是高性能计算、GPU、性能工程、并行算法，则优先 **CS149 / 15-418**。

两门都学时也建议分开学习，因为它们解决的是不同维度的“并发”。

## 建议路线

- 后端 / 分布式：系统基础 → OS / 网络 → MIT 6.5840。
- HPC / GPU：体系结构 → CS149 / 15-418。
- 系统方向深挖：两门都学，但分别完成核心项目。
