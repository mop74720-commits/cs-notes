# 操作系统课程选择分析

四门课程都讲操作系统，但实践环境、课程风格和适合人群不同。第一次学不建议四门并刷。

| 课程 | 主要特点 | 更适合 |
| --- | --- | --- |
| MIT 6.1810 / 6.S081 | 基于 xv6，强调通过实验理解 OS 内核 | 喜欢实现、希望深入内核 |
| UCB CS162 | 覆盖 OS 核心概念并配套大型系统项目 | 想要完整、强度较高的系统训练 |
| NJU OS | 中文课程，强调 OS 原理与动手实践 | 希望中文讲解 + 高质量实验 |
| HIT OS | 经典国内 OS 教学路线 | 希望按传统 OS 课程体系理解内核机制 |

## 怎么选

想“真正把 OS 写进手里”，MIT 6.1810 很合适；想体验更完整的大型系统课，可选 CS162。中文学习环境下，NJU OS 对自学者更友好。

重点不是看完多少套视频，而是 **至少完整做完一套实验**。

## 建议路线

CSAPP / C 基础 → 从 6.1810、CS162、NJU OS 中选一门主修 → 再用其他课程补遗漏主题。
