# 数据科学课程选择分析

当前只收录 **UCB Data100: Principles and Techniques of Data Science**，因此这里没有“几门课二选一”的问题。

Data100 适合已经具备 Python、基础概率/统计与线性代数后，系统学习数据处理、可视化、统计建模与数据科学工作流。

## 是否适合现在学

- 想做数据分析 / 数据科学：可以作为主线课程。
- 想做机器学习：Data100 是很好的数据处理与统计桥梁，但之后仍需要 ML 课程。
- 只做后端开发：不是必修，可以按兴趣选学。

## 建议路线

Python → 概率统计 + 线性代数 → Data100 → 机器学习 / 数据工程方向。
