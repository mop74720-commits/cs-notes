# 深度生成模型课程选择分析

这一栏已经明显进入进阶阶段，包含生成模型、扩散/SDE 与大语言模型三个方向。

| 课程 | 方向 | 更适合 |
| --- | --- | --- |
| 学习路线图 | 方向导航 | 不确定先学什么时先看 |
| MIT 6.S184 | 生成 AI、扩散与随机微分方程 | 想深入 diffusion / score-based generative models |
| CMU 11-667 | Large Language Models: Methods and Applications | 想系统理解 LLM 方法与应用 |
| CMU 11-868 | Large Language Model System | 关注 LLM 训练/推理系统与工程 |
| CMU 11-711 | Advanced NLP | 希望从高级 NLP 研究视角深入语言模型 |

## 怎么选

不要把 LLM Systems 与 LLM Methods 当成重复课。11-667 更偏模型方法与应用，11-868 更偏系统，11-711 更偏高级 NLP。

MIT 6.S184 属于另一条生成模型路线，重点在扩散/SDE，不需要因为学 LLM 就强制一起学。

## 建议路线

- 扩散生成：概率 + DL → MIT 6.S184。
- LLM 方法：DL/NLP → CMU 11-667 → 11-711。
- LLM 工程：DL + 系统基础 → 11-667（或同等模型基础）→ 11-868。
