# 机器学习课程选择分析

三门课可以理解为“友好入门”和“两套数学要求较高的大学 ML 主干课”。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| Coursera Machine Learning | 机器学习入门 | 第一次接触 ML，希望平滑建立直觉 |
| Stanford CS229 | 数学化的经典 ML | 已有线代、概率、微积分，想系统学习理论 |
| UCB CS189 | 大学级机器学习 | 希望同时接受较强数学与作业训练 |

## 怎么选

如果数学基础还不够，先 Coursera ML，不必硬上 CS229/CS189。

CS229 与 CS189 都可以作为主线进阶课，不建议第一次学习时两门并刷。选一门完整完成作业，比反复听相似理论更重要。

## 建议路线

- 初学：Coursera ML → CS229 或 CS189。
- 数学基础强：直接 CS229 / CS189。
- 后续研究：再进入深度学习、概率图模型、学习理论或 ML Systems。
