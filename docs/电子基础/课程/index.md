# 电子基础课程选择分析

当前课程可以分成“电子/信息设备基础”和“信号与系统”两层。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| UCB EE16A&B | 信息设备、线性代数、电路与系统综合基础 | 想从 CS 向 EE、机器人、控制、信号方向扩展 |
| UCB EE120 | 信号与系统 | 想系统学习连续/离散时间信号、系统分析 |
| MIT 6.007 | 信号与系统 | 与 EE120 同类，可作为另一套完整课程选择 |

## 怎么选

EE120 与 MIT 6.007 属于同赛道，通常 **选一门完整学完即可**，没有必要同时重复刷。

EE16A&B 更偏前置基础和综合工程视角。如果此前没有电路、线代和信号直觉，先 EE16A&B 再进入信号与系统更自然。

## 建议路线

- 纯 CS：按需要选学，不必作为强制主线。
- 机器人 / 控制 / 信号：EE16A&B → EE120 或 MIT 6.007。
- 已有电路与线代基础：直接在 EE120 与 6.007 中选一门。
