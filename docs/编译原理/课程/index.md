# 编译原理课程选择分析

这里收录了多所学校的完整编译器课程。它们覆盖内容高度重叠，因此核心原则是：**选一门作为主线，把编译器项目真正做完**。

| 课程 | 特点 | 更适合 |
| --- | --- | --- |
| PKU 编译原理实践 | 强调编译器实现实践 | 希望中文环境下动手做完整编译器 |
| Stanford CS143 | 经典编译原理课程 | 想系统学习词法、语法、语义、代码生成等 |
| NJU 编译原理 | 中文课程与实践结合 | 国内自学、希望课程资料易跟进 |
| KAIST CS420 | Compiler Design | 想体验另一套现代编译器课程 |
| USTC 编译原理与技术 | 中文体系化编译课程 | 希望按国内课程体系深入 |
| SJTU 编译原理 | 编译原理与实现 | 希望使用国内课程资源完整跟学 |

## 怎么选

如果是第一次学，Stanford CS143 或一套国内高质量课程（PKU / NJU / USTC / SJTU）选一门即可。

课程之间最重要的差异不是“谁的知识点更多”，而是 **作业框架、实现语言和项目完成度**。优先选择你愿意把实验做完的一套。

## 建议路线

数据结构 + 计算机系统基础 → 一门完整编译课程 → 再进入 LLVM、程序分析或编程语言课程。
