# 计算机图形学课程选择分析

当前课程覆盖基础图形学、实时渲染、物理动画和完整大学图形学课程。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| GAMES101 | 现代图形学入门 | 中文学习、快速建立渲染基础 |
| GAMES202 | 实时高质量渲染 | 已学 101，继续实时渲染方向 |
| GAMES103 | 基于物理的计算机动画 | 对物理模拟、动画感兴趣 |
| Stanford CS148 | 图形学课程与项目 | 想体验 Stanford 的工程型图形课程 |
| CMU 15-462 | 完整计算机图形学主干课 | 想系统、深入地学习图形学 |
| USTC CG | 中文计算机图形学课程 | 希望中文系统学习并配合高校课程资源 |

## 怎么选

第一次接触图形学，GAMES101 是低门槛入口；如果希望学得更完整、更学院化，可选择 CMU 15-462 或 USTC CG 作为主线。

GAMES202 与 GAMES103 是两个分支：前者偏实时渲染，后者偏物理动画，不需要都学。

## 建议路线

- 快速入门：GAMES101 → GAMES202。
- 系统路线：GAMES101 或 USTC CG → CMU 15-462。
- 动画/模拟：GAMES101 → GAMES103。
