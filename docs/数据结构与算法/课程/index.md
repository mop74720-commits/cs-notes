# 数据结构与算法课程选择分析

这组课程从“会写数据结构”逐渐走向“会证明和设计高级算法”。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| UCB CS61B | 数据结构 + 大量编程实践 | 需要扎实实现能力和工程训练 |
| Princeton Algorithms I & II | 经典数据结构与算法 | 希望以清晰课程体系系统入门 |
| MIT 6.006 | 算法设计与分析基础 | 已会编程，想建立更强算法分析能力 |
| MIT 6.046 | 高级算法设计与分析 | 已完成 6.006 或同等基础 |
| UCB CS170 | 高级算法与复杂性 | 想继续算法理论、NP、随机化等方向 |

## 怎么选

第一次系统学习时，**CS61B / Princeton Algorithms / MIT 6.006 不需要全部一起学**。

- 更重实现与项目：CS61B。
- 更偏经典算法课程、循序渐进：Princeton Algorithms I & II。
- 更重算法分析和理论：MIT 6.006。

6.046 与 CS170 都属于明显进阶层，应该在基础课之后再选。若目标是面试和工程，基础层学扎实通常比同时刷多门高级算法课更有效。

## 建议路线

- 工程型：CS61B → MIT 6.006 → 按需 6.046。
- 理论型：MIT 6.006 → 6.046 / CS170。
- 时间有限：CS61B 或 Princeton Algorithms 选一门完整做完。
