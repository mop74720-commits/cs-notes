# 数学基础课程选择分析

这里不把三门课当成互相替代的课程，因为它们解决的是三类不同基础问题。

| 课程 | 主要定位 | 更适合 |
| --- | --- | --- |
| MIT 18.01 / 18.02: Calculus | 单变量、多变量微积分 | 需要补连续数学、优化、概率与机器学习数学基础 |
| MIT 18.06: Linear Algebra | 线性代数 | 机器学习、图形学、数值计算、优化方向 |
| MIT 6.050J: Information Theory and Entropy | 信息、熵与信息论视角 | 已有基础概率，希望进入通信、编码、ML 理论等方向 |

## 怎么选

如果数学基础不完整，优先把 **微积分 + 线性代数** 补齐，它们不是二选一。面向一般 CS 学习，18.06 的收益非常直接；面向机器学习、优化、数值分析时，18.01/18.02 同样重要。

MIT 6.050J 更适合作为第二阶段课程。它不是替代微积分或线性代数的“第三门基础数学”，而是在这些基础之上引入信息量、熵等概念。

## 建议路线

- 通用 CS：18.06 + 按需补 18.01/18.02。
- ML / AI：18.01/18.02 → 18.06 → 概率 → 6.050J。
- 图形学 / 数值计算：18.06 与多变量微积分优先。
