# 数据库系统笔记

这里整理数据库学习与 Java 后端面试中最常用的 **MySQL、Redis 与数据库综合知识**。当前共 **5 篇**。

## 怎么选

| 笔记 | 定位 | 适合什么时候看 |
| --- | --- | --- |
| [MySQL笔记](MySQL/MySQL笔记.md) | MySQL 系统笔记 | 系统学习 SQL、索引、事务、锁等内容 |
| [面试-MySQL数据库](MySQL/面试-MySQL数据库.md) | MySQL 面试 | 面试前压缩复习 MySQL 高频问题 |
| [Redis笔记](Redis/Redis笔记.md) | Redis 系统笔记 | 学习数据结构、缓存与 Redis 常见机制 |
| [面试-Redis](Redis/面试-Redis.md) | Redis 面试 | 面试前快速梳理 Redis 高频问题 |
| [DB](数据库综合/DB.md) | 数据库综合 | 做跨主题复习与补充时 |

## 建议阅读顺序

1. **MySQL笔记**：关系数据库基础、索引、事务和锁是主线。
2. **Redis笔记**：再进入缓存、数据结构与高并发场景。
3. **DB**：补充数据库综合内容。
4. **面试-MySQL数据库 + 面试-Redis**：最后进行面试化复习。

如果目标是后端实习，优先把 **索引、事务 / MVCC、锁、Redis 数据结构、缓存问题** 学扎实，再记面试结论。
