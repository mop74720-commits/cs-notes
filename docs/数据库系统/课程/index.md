# 数据库系统课程选择分析

这组课程层次很清晰：数据库基础 → 数据库内核实现 → 更高级系统专题。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| UCB CS186 | 数据库系统基础与实现概念 | 第一次系统学数据库 |
| CMU 15-445 | 通过 BusTub 深入数据库内核 | 想实现 buffer pool、索引、执行器、并发等 |
| Caltech CS122 | 数据库系统实现 | 想从另一套实现型课程深入数据库内部 |
| Stanford CS346 | 数据库系统实现进阶 | 已有数据库系统基础，继续做系统实现 |
| CMU 15-799 | 数据库专题课 | 已经具备较强数据库背景，关注研究/高级主题 |

## 怎么选

如果目前主要是 Java 后端和数据库面试，优先 **CS186 建立完整概念，再做 CMU 15-445**。这比直接跳到高级专题课收益高得多。

15-445 与 CS122 都偏实现，不必一开始同时做；选一套完整项目做完，再根据兴趣补另一套。CS346 和 15-799 放到更后面。

## 建议路线

CS186 → CMU 15-445 或 CS122 → Stanford CS346 / CMU 15-799。
