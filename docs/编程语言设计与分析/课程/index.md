# 编程语言设计与分析课程选择分析

这一栏实际上包含三个不同方向：编程语言设计、程序静态分析、形式语义。

| 课程 | 方向 | 更适合 |
| --- | --- | --- |
| Stanford CS242 | Programming Languages | 想建立 PL 设计与语言机制全貌 |
| NJU 软件分析 | 静态程序分析 | 编译器、代码分析、程序验证方向 |
| PKU 软件分析 | 静态程序分析 | 想用另一套中文课程深入程序分析 |
| Cambridge Semantics of Programming Languages | 形式语义 | 理论 PL、形式化方法、证明方向 |

## 怎么选

四门课并不互相替代。第一次进入 PL 领域，先用 **CS242** 建立全貌通常更自然。

如果目标是编译器优化、静态分析或代码安全，可以从 NJU / PKU 软件分析中选一套主修。Cambridge Semantics 更数学化，适合已有离散数学、逻辑和 PL 基础后学习。

## 建议路线

CS242 → 软件分析（NJU / PKU）或形式语义（Cambridge），再按研究方向深入。
