# 人工智能课程选择分析

三门课覆盖的其实是三个不同入口：广义 AI、项目型 AI 入门、神经网络实现。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| UCB CS188 | 经典人工智能主干课 | 搜索、博弈、概率推断、MDP 等广义 AI |
| Harvard CS50 AI with Python | Python 项目驱动的 AI 入门 | 已会 Python，希望边做项目边理解 AI |
| Neural Networks: Zero to Hero | 从底层实现神经网络 | 想理解反向传播、语言模型和深度学习实现 |

## 怎么选

如果想知道“人工智能这门学科到底包括什么”，优先 **CS188**。如果更喜欢项目驱动、Python 友好路线，可以从 CS50 AI 开始。

Zero to Hero 实际更接近深度学习/神经网络专项，它不能替代 CS188 的广义 AI 内容，但非常适合为后续 LLM 与深度学习打基础。

## 建议路线

- 广义 AI：CS50 AI（可选）→ CS188。
- 深度学习 / LLM：Python → Zero to Hero → 深度学习课程。
