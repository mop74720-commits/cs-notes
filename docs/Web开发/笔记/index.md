## 建议阅读顺序

如果目标是 **Java 后端实习**，建议按下面顺序：

1. **JavaWeb-知识库笔记**：先补 Web 请求、响应、Servlet 等基础。
2. **SSM-知识库笔记**：建立 Spring / Spring MVC / MyBatis 主干。
3. **SSM-个人笔记**：结合个人学习记录查漏补缺。
4. **MyBatisPlus笔记**：掌握实际项目中更高频的持久层开发方式。
5. **面试-SpringBoot → 高频八股整理**：最后进入面试化复习。

> “知识库笔记”更适合系统学习；“个人笔记”更适合复盘；“面试”类笔记适合最后压缩记忆。
