# Web 开发课程选择分析

四门课程覆盖 Web 基础、完整全栈开发以及 React / 移动端 UI。

| 课程 | 定位 | 更适合 |
| --- | --- | --- |
| MIT Web Development Course | Web 开发基础与项目 | 想从大学课程体系进入 Web |
| Stanford CS142 | Web Applications | 想系统理解 Web 应用与前端基础 |
| Full Stack Open | 现代 JavaScript / React / Node 全栈实践 | 目标是尽快形成完整 Web 项目能力 |
| CS571 Building UI | React 与 React Native UI | 已有 Web 基础，想强化前端与移动端 |

## 怎么选

如果目标是“能做完整项目”，**Full Stack Open** 的路径最直接。想先打牢 Web 应用基础，可以选 Stanford CS142。

CS571 更适合已经确定走 React / React Native 前端的人，不是完整后端替代课程。

## 建议路线

- 全栈实战：CS142 或 MIT Web → Full Stack Open。
- 前端/移动端：Web 基础 → CS571。
- 后端方向：学到 HTTP、前后端交互、认证、数据库和部署即可，不必重复刷多套前端课。
